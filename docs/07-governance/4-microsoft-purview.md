# Microsoft Purview

## Definition

Microsoft Purview is a family of data governance, risk, and compliance solutions used to help organizations govern, protect, and manage their data estate.

It can provide visibility across data in environments such as on-premises, cloud, multi-cloud, and SaaS services.

## What Problem Does It Solve?

Use Microsoft Purview when the requirement focuses on **data governance** rather than Azure resource configuration.

Think:

```text
Govern / protect / understand DATA
across the data estate
→ Microsoft Purview
```

## Decision Factors

Do not confuse Purview with Azure Policy.

```text
Govern Azure RESOURCE configuration
→ Azure Policy

Govern and understand DATA estate
→ Microsoft Purview
```

Purview can help organizations gain visibility into data assets and manage data governance, security, risk, and compliance concerns.

## Exam Reasoning

```text
Resource configuration / compliance
→ Azure Policy

Data governance across environments
→ Microsoft Purview

Microsoft audit and compliance documentation
→ Service Trust Portal
```

> **Purview = data governance.**
