# Azure Regions

## Definition
An Azure region is a geographic area containing one or more datacenters connected by a low-latency network.

## What Problem Does It Solve?
Regions provide locations where Azure resources and services can be deployed.

## Region Selection Factors
- proximity to users
- data residency and compliance
- service availability
- availability requirements
- cost

## Region vs Availability Zone
```text
Deployment location / geographic area
→ Region

Physically separate datacenter location within a region
→ Availability Zone
```

## Exam Reasoning
Ask whether the scenario is choosing **where to deploy geographically** or protecting against a datacenter failure **inside one region**.
