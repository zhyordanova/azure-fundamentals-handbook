# Public Cloud

## Definition

A public cloud is a cloud deployment model in which computing resources are owned, managed, and operated by a third-party cloud service provider.

These resources are delivered over the Internet and are available to any customer who wants to use or purchase them.

**Microsoft Azure** is an example of a public cloud platform.

## Key Characteristics

A public cloud environment has the following characteristics:

- Infrastructure is owned and managed by the cloud provider.
- Services are delivered over the Internet.
- Resources are shared across multiple customers while remaining logically isolated.
- Pricing typically follows a consumption-based (pay-as-you-go) model.
- Customers do not purchase or maintain physical hardware.

## Advantages

Public cloud provides several important benefits:

- No upfront hardware investment.
- Rapid deployment of resources.
- High scalability and elasticity.
- Global availability across multiple Azure regions.
- Reduced operational overhead because Microsoft manages the infrastructure.

## Limitations

Compared to private cloud, organizations have:

- Less control over the underlying physical infrastructure.
- Responsibility to manage only the resources and services they deploy.
- Dependence on Internet connectivity to access cloud services.

## Microsoft Trigger Words

If a question contains words such as:

- third-party cloud provider
- available over the Internet
- pay-as-you-go
- provider-owned infrastructure
- Microsoft manages the infrastructure
- available to anyone

Think:

> Public Cloud

## Common Exam Questions

Microsoft frequently asks questions such as:

- Which cloud deployment model provides services over the Internet?
- Which deployment model uses infrastructure owned by a third-party provider?
- Which cloud model uses consumption-based pricing?
- Which deployment model does Microsoft Azure represent?

## Common Mistakes

❌ Thinking Public Cloud means public access to your data.

Public cloud means the infrastructure is shared, but customer resources remain logically isolated and protected.

❌ Thinking organizations own the hardware.

In a public cloud, the cloud provider owns and operates the physical infrastructure.

## Compare With

| Public Cloud | Private Cloud |
|--------------|---------------|
| Provider owns infrastructure | Organization owns or controls infrastructure |
| Pay-as-you-go | Hardware investment (CapEx) |
| Available over the Internet | Dedicated to one organization |
