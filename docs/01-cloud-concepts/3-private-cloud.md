# Private Cloud

## Definition
A private cloud is a cloud environment dedicated to a single organization.

## What Problem Does It Solve?
It provides cloud characteristics while giving one organization dedicated use of the cloud environment.

## Key Characteristics
- dedicated to one organization
- greater control over the environment
- can be hosted on-premises or by a third party

> **Important:** Private cloud does not necessarily mean on-premises.

## Decision Factors
```text
Cloud environment dedicated to one organization
→ Private Cloud
```

## Compare With
| Requirement | Model |
|---|---|
| Provider-operated cloud platform | **Public Cloud** |
| Dedicated cloud environment | **Private Cloud** |
| Combine private/on-premises and public cloud | **Hybrid Cloud** |

## Exam Reasoning
Ask **who the environment is dedicated to**, not simply where the hardware is located.
