After completing this chapter, you will be able to:

- Explain the core benefits of cloud computing.

# What is Cloud Computing?

Cloud computing is the delivery of computing services over the Internet.

Instead of purchasing, installing, and maintaining physical infrastructure, organizations consume IT resources on demand from a cloud provider such as Microsoft Azure.

These services include:

- Compute
- Storage
- Networking
- Databases
- Identity
- Analytics
- Artificial Intelligence

Cloud resources can typically be provisioned within minutes and organizations pay only for the resources they consume.

## Why Cloud Computing Exists

Before cloud computing, organizations had to build and maintain their own IT infrastructure.

This required:

- Purchasing physical servers
- Building or renting datacenters
- Maintaining hardware
- Replacing failed equipment
- Planning hardware capacity years in advance

Cloud computing removes most of this operational burden by allowing organizations to consume infrastructure as a service instead of owning it.

## Key Characteristics

Cloud computing provides:

- On-demand resource provisioning
- Consumption-based pricing
- Rapid deployment
- Elastic resource allocation
- Global availability

## Microsoft Trigger Words

When a question contains words such as:

- on-demand
- pay-as-you-go
- consumption-based
- provision
- cloud provider
- Internet

Think:

> Cloud Computing

## Common Exam Questions

Microsoft typically asks questions such as:

- What is cloud computing?
- Which cloud benefit allows resources to be deployed quickly?
- Which cloud model requires purchasing hardware?
- Which deployment model combines on-premises and cloud resources?

## Common Mistakes

❌ Thinking cloud computing means "virtual machines only."

Cloud computing includes many managed services such as databases, storage, networking, identity, AI, and analytics.

❌ Assuming cloud always means Public Cloud.

Cloud computing includes Public, Private, and Hybrid deployment models.

## Exam Tip

Microsoft rarely asks for the definition of cloud computing directly.

Instead, the exam usually tests cloud concepts through scenarios involving:

- scalability
- elasticity
- deployment models
- pricing
- responsibility
